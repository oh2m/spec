# Security Policy

## Supported Versions

Only the latest draft of the OH2M specification is currently active and supported. Security fixes will be applied directly to the latest draft version.

| Version | Supported |
| ------- | --------- |
| v0.1.1  | Yes       |
| < v0.1.1| No        |

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern within the OH2M specification or its reference implementations, please do not open a public issue. Instead, report it privately to help protect users' private health data.

Please email your report to the maintainers at **[TODO: email]** with:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or illustrate the vulnerability.
- Any suggested remediations or mitigations.

We will acknowledge your report within 48 hours and work with you to resolve the issue before making a public disclosure.
